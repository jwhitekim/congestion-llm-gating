# 연구 결과

본 연구는 실내 혼잡도 모니터링에서 규칙 기반 이벤트로 LLM 호출 구간을 선별해서 호출량을 약 74프로 감소시켰고.
Always-call 평가에서 206개는 LLM이 anomaly으로 판정했지만 그중에 내가 판단한 anomaly으로 101개를 걸러냈다. 
트리거되지 않은 구간에서도 105개의 caution/anomaly 판정이 나타났다. 

# 한계점

다만 llm 판정 자체를 정답으로 볼 수 없으며, 현재 규칙의 수치 조건 역시 절대적인 혼잡 기준이라고 볼 수 없다. 

# 향후 과제

따라서 향후 실제 영상을 기반으로 사람의 독립적인 평가와 LLM 판정이랑 비교하여 혼잡의 정의와 평가 기준을 명확히 하고, 트리거 조건 등 검증과 보완할 필요가 있다.
